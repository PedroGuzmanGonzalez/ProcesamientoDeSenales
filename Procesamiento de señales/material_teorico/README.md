# Material teórico

Guardar aquí los archivos de teoría de la materia: PDFs, presentaciones, documentos e imágenes de apuntes.

Se pueden colocar directamente en esta carpeta. Si el material corresponde a una clase específica, se puede crear una subcarpeta con su fecha (`AAAA-MM-DD/`).

Usar nombres descriptivos, por ejemplo `Introduccion_a_senales.pdf`, y enlazar el material desde los apuntes de `teoria/` cuando corresponda:

```markdown
[Material de la clase](../material_teorico/Introduccion_a_senales.pdf)
```
